Claro! 😄 Vamos destrinchar o Baozeira como se fosse um projeto de verdade. Uma análise de requisitos serve para definir o que o site precisa fazer, quem vai usar, quais funções terá e quais regras o sistema deve seguir.

Como já temos várias ideias do Baozeira, podemos montar a análise assim:

🍔 1. Identificação do sistema

Nome: Baozeira
Tipo: Site de vendas de alimentos
Objetivo: Oferecer produtos alimentícios inspirados na culinária asiática com uma identidade brasileira, permitindo que clientes visualizem o cardápio, façam pedidos e acompanhem suas compras.

🎯 2. Objetivo do sistema

O site deverá permitir que os clientes:

  • Visualizem os produtos disponíveis.

  • Consultem preços e promoções.

  • Conheçam os produtos através de imagens.

  • Adicionem produtos ao pedido.

  • Realizem cadastro e login.

  • Finalizem pedidos.

  • Entrem em contato com a Baozeira.

  • Visualizem avaliações/depoimentos.

  • Conheçam a empresa.

Além disso, deverá existir uma área administrativa para que o responsável pelo Baozeira consiga gerenciar os produtos, promoções e pedidos.

👥 3. Usuários do sistema

Teremos basicamente dois tipos de usuários:

👤 Cliente

Pode:

  • Criar uma conta.

  • Fazer login.

  • Visualizar o cardápio.

  • Ver detalhes dos produtos.

  • Adicionar produtos ao carrinho.

  • Fazer pedidos.

  • Consultar seus pedidos.

  • Avaliar produtos/serviço.

  • Entrar em contato.

🔐 Administrador

Pode:

  • Fazer login administrativo.

  • Cadastrar produtos.

  • Editar produtos.

  • Excluir produtos.

  • Alterar preços.

  • Alterar imagens.

  • Criar promoções.

  • Editar promoções.

  • Visualizar pedidos.

  • Atualizar status dos pedidos.

  • Gerenciar informações do site.

⚙️ 5. Requisitos não funcionais

Esses requisitos definem como o sistema deve funcionar.

RNF01 — Usabilidade

O site deve possuir uma interface simples e fácil de utilizar.

RNF02 — Responsividade

O site deve funcionar em:

  • 💻 Computadores

  • 📱 Celulares

  • 📲 Tablets

RNF03 — Segurança

As senhas dos usuários não devem ser armazenadas de forma exposta.

RNF04 — Desempenho

As páginas devem carregar rapidamente, evitando imagens excessivamente pesadas.

RNF05 — Compatibilidade

O site deve funcionar nos principais navegadores, como Chrome, Edge e Firefox.

RNF06 — Identidade visual

O sistema deve manter a identidade visual do Baozeira, utilizando principalmente preto, amarelo e vermelho.

📝 9. Regras de negócio

Aqui entram as regras que o sistema deve respeitar.

RN01: Um cliente precisa estar cadastrado para finalizar um pedido.

RN02: Um produto precisa possuir nome e preço para ser exibido no cardápio.

RN03: Produtos indisponíveis não devem poder ser adicionados ao carrinho.

RN04: O valor total do pedido deve ser calculado automaticamente.

RN05: Somente administradores podem cadastrar, editar ou excluir produtos.

RN06: Somente administradores podem alterar o status dos pedidos.

RN07: O cliente deve conseguir visualizar apenas os próprios pedidos.

⭐ 10. Diferencial do Baozeira

Um ponto interessante para colocar na análise é que o Baozeira não seria apenas um site comum de comida.

A proposta seria:

Unir sabores e referências da culinária asiática com a criatividade e identidade brasileira em uma experiência de alimentação moderna, divertida e acessível.

Isso ajuda a explicar por que o Baozeira existe, e não apenas quais funcionalidades ele possui.
